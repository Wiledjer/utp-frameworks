# Навигация в лабораторных

Во все HTML-файлы внутри `works/` добавлена фиксированная кнопка:

```text
← К лабораторным
```

Кнопка ведёт на страницу списка всех лабораторных:

```text
labs/index.html
```

Так пользователь из любой отдельной работы возвращается не на начало портфолио, а именно к списку лабораторных работ.
