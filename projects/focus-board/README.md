# FocusBoard

**FocusBoard** — минималистичная панель задач для учебного frontend-портфолио.

## Возможности

- добавление задачи;
- удаление задачи;
- статусы `Todo`, `In Progress`, `Done`;
- фильтр по статусу;
- счётчики задач;
- сохранение задач в `localStorage`;
- переключение светлой/тёмной темы.

## Почему проект подходит для портфолио

Проект показывает базовые навыки frontend-разработки без лишнего усложнения:

- семантическая HTML-структура;
- современный CSS;
- адаптивная сетка;
- DOM-события;
- работа с массивом данных;
- сохранение состояния в браузере.
